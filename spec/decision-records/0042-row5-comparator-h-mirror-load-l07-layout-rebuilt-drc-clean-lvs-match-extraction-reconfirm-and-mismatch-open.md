## Context

0039-0041 left the layout side open: `layout/cells/rcosc_comparator.gds`, `rcosc_top.gds`, `layout/lvs_ref/*` and `layout/reports/*` still described `MLOADA` / `MLOADB` at L=1u.

## Evidence

- **Cell sharing:** comparator H (`rcosc_comparator`) and comparator L (`rcosc_comparator_p`) are separate layout cells (`layout/run_checks.sh` `CELLS`, `build_cells.py`); `MLOAD*` exist only in H. Rebuilding changed exactly `rcosc_comparator.gds` and `rcosc_top.gds` (and their LVS references); `rcosc_bias`, `rcosc_trim_bank` and `rcosc_comparator_p` GDS are byte-identical.
- **Toolchain:** the pinned klayout-tools 0.4.0 / klayout 0.30.12 in a throwaway venv (never the host `klt`). `layout/run_checks.sh` cannot run end to end under that pin: its first step, `design/regen-netlist.sh`, calls `klt netlist`, which 0.4.0 lacks. The netlists were already regenerated by 0039 and `design/check-netlist-consistency.py` passes, so the remaining steps were run by hand: `build_cells.py`, then the script's per-cell DRC / extract / LVS loop verbatim, then `klt erc` on 0.8.0 as the script specifies.
- **Results:** DRC clean on all five cells. LVS: `rcosc_comparator` match (no tolerated deltas, extracted L = 0.7u pair), `rcosc_top` match (6 `device.parameter_tolerated` + 1 `topology.flattened`, the same tolerated classes as before), the other cells match. ERC: no supply findings; 62 `erc.floating_gate` (the disclosed Contact-omission artifact).
- **Signoff:** `rcosc_top.gds` hash changed, so `signoff/layout-envelope.json` and the three manifest pins were re-pinned and `signoff-report.json` re-graded with klayout-tools 0.8.0; `verify-report.py` passes (8/11, unchanged).
- Reports of unchanged cells were not committed (path-only churn).
